# 🧠 Multi-Agent Planner with YandexGPT & Observability

Мультиагентная система планирования на базе YandexGPT с полной наблюдаемостью (observability) и системой управления промптами через базу данных.

## 🚀 Возможности

- ✅ **Мультиагентная архитектура** на базе LangGraph
- ✅ **Интеграция с YandexGPT** через REST API
- ✅ **Полная наблюдаемость** с Langfuse (трейсинг, метрики, логи)
- ✅ **Управление промптами через SQLite** (версионирование, переключение на лету)
- ✅ **CLI-интерфейс** для управления промптами
- ✅ **Автоматическая генерация PDF-отчетов**
- ✅ **Сбор метрик** (токены, задержки, стоимость)
- ✅ **История изменений** промптов
