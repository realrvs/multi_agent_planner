Проект полностью соответствует принципам Workload Identity in Multi-System
Environments (WIMSE) согласно черновикам IETF.

┌─────────────────────────────────────────────────────────────────────────────┐
│  ФАЗА 1: ИДЕНТИЧНОСТЬ АГЕНТОВ (WIT)                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│  • Каждый агент получает уникальный Workload Identity Token (WIT)         │
│  • Токены подписываются и верифицируются криптографически                  │
│  • Аттестация агентов: проверка целостности и окружения                   │
│  • Peer-to-peer верификация между агентами                                │
│  • Реализовано в: config/identity.py, agents/base_agent.py                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  ФАЗА 2: ПЕРЕДАЧА КОНТЕКСТА БЕЗОПАСНОСТИ                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│  • WIT-токены передаются между агентами в цепочке вызовов                 │
│  • Каждый агент проверяет родительский WIT перед выполнением              │
│  • Отслеживание session_id и user_id через весь workflow                  │
│  • Полная цепочка делегирования: Research → Analysis → Execution          │
│  • Реализовано в: graph/state.py, graph/nodes.py, agents/base_agent.py    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  ФАЗА 3: ПОЛИТИКИ БЕЗОПАСНОСТИ (НАИМЕНЬШИЕ ПРИВИЛЕГИИ)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│  • Ограничение делегирования: кто кому может передавать управление        │
│  • Контроль доступа к инструментам (allowed_tools)                        │
│  • Требование одобрения человека для критических действий (Execution)     │
│  • Ограничение контекста (max_context_length) для каждого агента          │
│  • Политики хранятся в промптах и могут обновляться на лету               │
│  • Реализовано в: config/prompts.py, agents/base_agent.py                 │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  ФАЗА 4: АУДИТ И НАБЛЮДАЕМОСТЬ                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  • Полное логирование всех действий агентов                               │
│  • Каждая проверка политики фиксируется в аудите                          │
│  • Все LLM-вызовы отслеживаются с метриками (латенси, токены, стоимость)  │
│  • Интеграция с Langfuse для визуализации трейсов                         │
│  • Генерация JSON-отчётов об аудите (audit_report.json)                   │
│  • Реализовано в: config/wimse_audit.py, config/observability.py          │
└─────────────────────────────────────────────────────────────────────────────┘

📦 УСТАНОВКА И НАСТРОЙКА
================================================================================

1.  Клонирование репозитория:
    git clone https://github.com/realrvs/multi_agent_planner.git
    cd multi_agent_planner

2.  Создание и активация виртуального окружения:
    python -m venv venv
    source venv/bin/activate        # Linux/Mac
    .\venv\Scripts\Activate.ps1     # Windows

3.  Установка зависимостей:
    pip install -r requirements.txt
    pip install PyJWT cryptography  # Для WIMSE

4.  Настройка переменных окружения (.env):
    cp .env.example .env
    # Заполните .env реальными ключами:
    # - YANDEX_API_KEY (обязательно)
    # - YANDEX_FOLDER_ID (обязательно)
    # - WIMSE_SECRET_KEY (обязательно, своё значение)
    # - LANGFUSE_ENABLED (опционально, для аудита)

5.  Проверка WIMSE-идентичности:
    python test_identity.py

6.  Проверка передачи контекста:
    python test_context.py

7.  Проверка политик безопасности:
    python test_policies.py

8.  Полное тестирование WIMSE:
    python test_full_wimse.py
